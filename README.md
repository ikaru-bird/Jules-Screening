# 株式スクリーニング・チャート生成ツール

## 概要

このプロジェクトは、特定の財務基準とチャートパターンに基づいて株式をスクリーニングし、条件に合致した銘柄のチャートを自動生成するツールです。

ワークフローは以下の通りです。
1.  **データ取得**: Finviz.comから、あらかじめ定義された条件に合う銘柄のティッカーリストをスクレイピングします。
2.  **スクリーニング**: 取得したティッカーリストを元に、yfinanceライブラリを使って各銘柄の詳細な財務データ（ROE、EPS成長率など）と株価履歴を取得し、オニール流の投資基準およびカップウィズハンドル・パターンの有無を判定します。
3.  **チャート生成**: スクリーニングを通過した銘柄について、価格、出来高、MACD、および基本的な財務情報を記載したチャート画像（PNG形式）を生成・保存します。

## セットアップ方法

1.  必要なライブラリをインストールします。
    ```bash
    pip install -r requirements.txt
    ```
2.  （オプション）チャートに日本語を表示したい場合、`IPAexGothic`フォントをシステムにインストールしてください。

## 実行方法

（リファクタリング後、`main.py`をエントリーポイントとする予定です）

1.  **Finvizからティッカーリストを取得する:**
    ```bash
    python main.py scrape
    ```
    これにより、`tickers.csv`が生成（または上書き）されます。

2.  **スクリーニングとチャート生成を実行する:**
    ```bash
    python main.py screen
    ```
    このコマンドは`tickers.csv`を読み込み、基準を満たした銘柄を`screening_results.csv`に保存し、同時に各銘柄のチャート（例：`AAPL.png`）をルートディレクトリに保存します。
