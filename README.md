# 株式スクリーニング・チャート生成ツール

## 概要

このプロジェクトは、特定の財務基準とチャートパターンに基づいて株式をスクリーニングし、条件に合致した銘柄のチャートを自動生成するツールです。

ワークフローは以下の通りです。
1.  **データ読み込み**: `_files/US/input.txt` のような、ティッカー、会社名、業種情報を含むローカルファイルを読み込みます。
2.  **スクリーニング**: 読み込んだティッカーリストを元に、yfinanceライブラリを使って各銘柄の詳細な財務データ（ROE、EPS成長率など）と株価履歴を取得し、オニール流の投資基準およびカップウィズハンドル・パターンの有無を判定します。
3.  **チャート生成**: スクリーニングを通過した銘柄について、価格、出来高、MACDに加え、**会社名と業種**を記載したチャート画像（PNG形式）を`output/`ディレクトリに生成・保存します。

## セットアップ方法

1.  必要なライブラリをインストールします。
    ```bash
    pip install -r requirements.txt
    ```
2.  （オプション）チャートに日本語を表示したい場合、`IPAexGothic`フォントをシステムにインストールしてください。

## 実行方法

1.  **スクリーニングとチャート生成を実行する:**
    ```bash
    python main.py screen
    ```
    このコマンドは、デフォルトで `_files/US/input.txt` を読み込みます。

    別の入力ファイルを指定したい場合は、`--input-file` (または `-i`) 引数を使用します。
    ```bash
    python main.py screen --input-file path/to/your/tickers.txt
    ```

2.  **結果の確認:**
    *   スクリーニングを通過した銘柄のリストが `screening_results.csv` に保存されます。
    *   各銘柄のチャート画像（例：`NVDA_WATCH.png`）が `output/` ディレクトリに保存されます。チャートには会社名と業種が表示されます。

## 入力ファイルのフォーマット

入力ファイルは、各行がチルダ(`~`)で区切られたテキストファイルである必要があります。最低限、以下の3つの情報が必要です。

`ティッカー~会社名~業種`

例:
```
NVDA~NVIDIA Corp~Technology
MSFT~Microsoft Corporation~Technology
```
